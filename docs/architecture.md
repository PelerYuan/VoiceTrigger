# 架构与边界

```text
麦克风 / RTSP / 文件
          ↓
PCM 单声道 16 kHz
          ↓
采集线程：能量门限 + 预缓冲 + 静音分段 + 长语音重叠
          ↓
有界队列
          ↓
主线程：Silero VAD + Whisper 转写
          ↓
Unicode 归一化 + 关键词匹配 + 独立冷却
          ↓
stdout JSON / JSONL 文件
```

## 线程与积压

采集线程不等待持续输入的推理，队列满时丢掉最旧片段以避免无限积压和无限内存增长。这会漏掉被丢弃片段里的关键词，因此告警不能忽略。文件输入采取背压等待，保证待处理片段不因队列容量丢弃。

## 匹配语义

采用 NFKC 和 casefold。中文关键词允许字间空格；英文词使用 Unicode 词边界，避免 `Ann` 命中 `banana`。不会自动转换繁简、拼音、同音字，也不区分谁说的名字。电视中出现名字同样可能触发。

长片段的重叠降低切分边界的截断概率；冷却减少重复命中，但不是持久化去重，也不能识别是否为同一次真实呼叫。

## 故障恢复

持续音频输入中断后重连。文件输入失败会退出报错。GPU、模型加载或推理失败不会静默切 CPU；容器配置 `unless-stopped`，启动失败时可能持续重启，维护者需要查看日志。

## 非目标

当前没有实时网络事件传输和桌面通知，也没有认证、TLS、事件重放、日志轮转、健康检查 API 或准确率服务等级承诺。添加文档和 CI 不代表这些能力已完成。
